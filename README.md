# LockTime

Простий опенсорсний блокувальник для Android. Обираєте додатки (Instagram, TikTok…),
ставите денний ліміт (наприклад, 1 година) — і коли час вийшов, додаток просто
не відкривається до опівночі. Жодних паролів і кнопок «ще 5 хвилин».

- без реклами, без інтернету, без акаунтів — усе лишається на телефоні;
- без сторонніх бібліотек — лише Android SDK і Kotlin;
- розраховано на Samsung (One UI), підтримує Android 8.0+.

## Як це працює

- **Ліміт на день** для кожного додатка окремо. Час рахується від опівночі
  за системною статистикою Android.
- Коли ліміт вичерпано, служба спеціальних можливостей повертає вас на головний
  екран і показує «Час на сьогодні вийшов». Поки додаток відкритий, перевірка
  йде кожні 3 секунди, тож вилетите навіть посеред стрічки.
- **Посилити — одразу, послабити — завтра.** Зменшити ліміт чи додати новий
  додаток можна будь-коли. Збільшити ліміт, прибрати його чи вимкнути захист —
  зміна запрацює лише з наступного дня.
- **Захист від видалення** (необов'язковий): поки увімкнений, сторінки
  налаштувань, де згадується LockTime (видалення, «Примусово зупинити»,
  вимкнення служби), одразу закриваються.

## Встановлення

1. Завантажте `LockTime.apk` з вкладки **Releases** (або **Actions** → останній
   запуск → `LockTime-apk`).
2. Відкрийте файл на телефоні й дозвольте встановлення з цього джерела.
3. Відкрийте LockTime і надайте три дозволи вгорі екрана:
   - **Статистика використання** — щоб знати, скільки часу ви провели в додатку;
   - **Служба спеціальних можливостей** — щоб помічати відкриття й закривати додаток;
   - **Без оптимізації батареї** — щоб Samsung не «присипляв» LockTime.

> **Samsung / Android 13+:** для встановлених не з Play Market додатків перемикач
> спеціальних можливостей може бути сірим («Обмежене налаштування»). Тоді:
> Налаштування → Програми → LockTime → ⋮ (угорі праворуч) →
> **Дозволити обмежені налаштування**, і ввімкніть службу ще раз.

4. Торкніться потрібних додатків у списку і вкажіть хвилини на день.

## Збірка з коду

Автоматично: кожен push у `main` збирає APK у GitHub Actions. Щоб опублікувати
реліз, створіть тег:

```bash
git tag v1.0
git push origin v1.0
```

Локально (потрібен Android SDK або Android Studio):

```bash
./gradlew assembleDebug
# результат: app/build/outputs/apk/debug/app-debug.apk
```

## Чесно про обмеження

На Android будь-який блокувальник можна обійти, бо система дає власнику телефона
повний контроль. Наприклад: безпечний режим (Safe Mode), зміна дати/часу в
налаштуваннях, вхід у Instagram через браузер. LockTime не робить це неможливим —
він робить це довгим і незручним, а цього в момент спокуси зазвичай досить.

Також: APK, зібраний GitHub Actions, підписаний тимчасовим debug-ключем. Якщо
оновлення не встановлюється поверх старої версії — видаліть стару
(налаштування лімітів скинуться).

## Структура

| Файл | Що робить |
|---|---|
| `LimitService.kt` | служба спец. можливостей: стежить за відкритим додатком і блокує |
| `UsageTracker.kt` | рахує час у кожному додатку від опівночі |
| `Prefs.kt` | зберігає ліміти, правило «послабити — лише завтра» |
| `MainActivity.kt` | головний екран: дозволи, список додатків, ліміти |
| `BlockActivity.kt` | екран «Час на сьогодні вийшов» |
